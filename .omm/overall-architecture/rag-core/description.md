The question-answering pipeline in src/attack_qa/: query understanding (query.py, intent.py, lookups.py), hybrid retrieval (bm25_index.py, dense_index.py, embedding.py, fusion.py, retrieval.py), answering with refusal gates and a citation check (answer.py, language.py), and LLM providers behind one AnswerModel interface (llms.py, openai_compat_model.py, gemini_model.py, claude_model.py). Shared unchanged by the demo API and every evaluation script.
