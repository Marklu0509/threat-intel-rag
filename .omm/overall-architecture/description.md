threat-intel-rag answers questions about MITRE ATT&CK (v19.2) with cited answers or explicit refusals. Visitors use a static page on GitHub Pages (rag.marklu.page); live questions go to a FastAPI service on Azure Container Apps, which runs the RAG core: query understanding, hybrid BM25 + bge-m3 retrieval, two refusal gates, a structured-output LLM call, and a citation check. Offline, a data build turns ATT&CK STIX into 2,091 passages and an index, and an evaluation harness measures retrieval, answers, faithfulness and attacks on the same pipeline.
