Static page at https://rag.marklu.page (GitHub Pages): site/index.html, site/app.js (~400 lines, vanilla JS), site/styles.css and site/demo-data.json. Shows recorded evaluation examples (answers, refusals, failures, attacks) with citations and retrieval traces, and a live question box. On load it calls /health in the background to hide the API cold start; questions are POSTed to /ask. Answers render as a document with footnote citations, not a chat (Q46); styling follows the author's personal site (Q47). The API URL is the Azure default host, since Container Apps Express has no custom domains (Q54).
