attacks.py defines 10 target questions × 7 attacks (3 direct injection, 2 indirect injection in a passage, 2 poisoned passages = gold text plus one planted line) and scores them with canary strings (ZEBRA-7731, ZebraShield). scripts/evaluate_attacks.py runs them per defense configuration on fresh attack-test copies of the index (production code refuses to open them) and checks the production index's content fingerprint (index_fingerprint.py) before and after.
