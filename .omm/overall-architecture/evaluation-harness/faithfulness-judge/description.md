faithfulness.py judges each claim against only the passages it cites (supported / partial / unsupported, reason before verdict, rubric in RUBRIC); claims citing nothing or a missing passage are unsupported by rule. judge_model.py calls Claude Sonnet via OpenRouter (a different model family from the Qwen answerer). agreement.py builds a stratified blind labelling sheet and computes linear-weighted Cohen's kappa (0.873 on 40 claims).
