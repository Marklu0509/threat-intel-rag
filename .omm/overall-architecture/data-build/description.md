Offline build of the data the pipeline searches: scripts/build_passages.py downloads ATT&CK Enterprise v19.2 (SHA-256 checked), parses STIX, cleans text and writes 2,091 passages plus the revoked-ID table to data/processed/; scripts/build_index.py embeds them with bge-m3 into a Chroma index in data/index/. For deployment the evaluated output is packed into a GitHub Release tarball (v0.1.0). See the pipeline perspective for the stages.
