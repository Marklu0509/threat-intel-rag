src/attack_qa/web/main.py. Reads settings from the environment (ALLOWED_ORIGINS, default https://rag.marklu.page, a wildcard is refused; DEMO_LLM, default groq; APP_VERSION = git SHA from the image build), loads passages, the Chroma index, bge-m3, the intent classifier and the LLM, runs one warm-up retrieval, then builds the app. The app is only built when ATTACK_QA_SERVE=1, so importing the module in tests loads nothing heavy.
