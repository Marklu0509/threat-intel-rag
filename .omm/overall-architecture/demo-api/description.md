FastAPI service (src/attack_qa/web/) exposing GET /health (optionally ?check=llm) and POST /ask. main.py loads the real passages, index, bge-m3 and LLM and warms retrieval before /health reports ready; app.py builds the app from injected parts (tests pass a tiny index and a fake model); limits.py holds in-memory rate limits. Runs as one replica on Azure Container Apps Express in Japan West, 1 vCPU / 2 GiB.
