passages.py builds three passages per technique following ATT&CK's own structure (ADR 0002): Overview (with tactics, platforms and sub-technique list), Mitigation (complete list) and Detection. Each starts with a passage heading naming the technique, parent and kind. Techniques with no mitigation get an explicit No-mitigation statement (201 of them); 6 parents whose sub-techniques have mitigations point to those instead (Q22). passage_io.py reads and writes passages.jsonl.
