Offline data pipeline, run with scripts/build_passages.py and scripts/build_index.py: download ATT&CK Enterprise v19.2, parse STIX, clean text, build three passages per technique (697 techniques → 2,091 passages) with a revoked-ID table, embed them with bge-m3 into a Chroma index, then (for deployment) pack the evaluated output into the v0.1.0 GitHub Release, which CI verifies and bakes into the API image. BM25 is not stored: it is rebuilt in memory from passages.jsonl at startup.
